سیاست حفظ حریم خصوصی Lumen

آخرین به‌روزرسانی: ۲۴ سپتامبر ۲۰۲۶

Lumen یک افزونهٔ Chrome برای خلاصه‌سازی صفحهٔ فعال با سرویس‌های هوش مصنوعی سازگار با OpenAI است. این سیاست توضیح می‌دهد چه داده‌ای پردازش می‌شود و چه کسی آن را دریافت می‌کند.

داده‌هایی که پردازش می‌شوند

پس از اینکه کاربر دکمهٔ خلاصه‌سازی را می‌زند و رضایت خود را تأیید می‌کند، افزونه برای خلاصه‌سازی صفحهٔ فعال این اطلاعات را می‌خواند:

  • عنوان و نشانی صفحهٔ فعال
  • توضیح متای صفحه، در صورت وجود
  • متن قابل‌خواندن صفحه، حداکثر حدود ۱۸٬۰۰۰ نویسه
  • نام مدل و پیام سیستمی که کاربر در تنظیمات وارد می‌کند

صفحات داخلی Chrome مانند chrome:// و Chrome Web Store قابل خواندن نیستند. خلاصهٔ تولیدشده فقط در حافظهٔ موقت پنجرهٔ افزونه نگه داشته می‌شود و به‌صورت خودکار ذخیره نمی‌شود.

API و کلید دسترسی

نشانی سرویس API و کلید API در تنظیمات افزونه وارد می‌شوند. کلید در chrome.storage.local همان مرورگر ذخیره می‌شود و در کد یا بستهٔ افزونه قرار ندارد. هنگام خلاصه‌سازی، کلید فقط به همان سرویسی ارسال می‌شود که کاربر انتخاب کرده است.

برای سرویس‌های آنلاین، نشانی باید HTTPS باشد. HTTP فقط برای مدل‌های محلی روی localhost یا 127.0.0.1 مجاز است. سرویس API انتخابی ممکن است داده‌های ارسالی را طبق سیاست حفظ حریم خصوصی و شرایط استفادهٔ خود نگه دارد؛ این موضوع به ارائه‌دهندهٔ همان سرویس بستگی دارد.

اشتراک‌گذاری و تحلیل

Lumen تبلیغ، تحلیل رفتار کاربر یا فروش داده ندارد و سرور واسطی برای دریافت خلاصه‌ها ندارد. دادهٔ صفحه فقط برای اجرای درخواست خلاصه‌سازی به ارائه‌دهندهٔ API انتخابی فرستاده می‌شود. افزونه برای خواندن صفحه از دسترسی موقت activeTab و برای تنظیمات از storage استفاده می‌کند؛ دسترسی به میزبان API فقط پس از تأیید کاربر درخواست می‌شود و در صورت لغو رضایت حذف می‌گردد.

حذف داده‌ها

برای حذف کلید و تنظیمات ذخیره‌شده، افزونه را حذف کنید یا داده‌های ذخیره‌شوندهٔ آن را از تنظیمات Chrome پاک کنید. برای حذف داده‌ای که ارائه‌دهندهٔ API دریافت کرده است، باید مستقیماً با همان ارائه‌دهنده تماس بگیرید؛ Lumen به آن سرویس دسترسی مدیریتی ندارد.

تغییرات و تماس

اگر پرسشی دربارهٔ این سیاست دارید، از راه ارتباطی درج‌شده در صفحهٔ افزونه در Chrome Web Store استفاده کنید. پیش از انتشار عمومی، نشانی پشتیبانی واقعی را در این صفحه و در اطلاعات فروشگاه جایگزین کنید.

این متن به‌صورت محلی در بستهٔ افزونه قرار دارد. برای Chrome Web Store باید همین سیاست را در یک URL عمومی HTTPS (مثلاً GitHub Pages) منتشر کنید و آن URL را در فرم انتشار ثبت کنید.
