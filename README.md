# Lumen — خلاصه‌سازی صفحه با هوش مصنوعی

یک افزونهٔ سبک و زیبا برای Chrome که صفحهٔ فعلی را با مدل OpenAI-compatible دلخواه شما خلاصه می‌کند. رابط کاربری فارسی و راست‌به‌چپ است و خلاصهٔ Markdown به‌صورت قالب‌بندی‌شده نمایش داده می‌شود.

## نصب افزونه

اگر فایل `lumen-ai-page-summarizer.zip` را دارید، ابتدا آن را از حالت فشرده خارج کنید. سپس:

1. آدرس `chrome://extensions` را باز کنید.
2. گزینهٔ **Developer mode** یا «حالت توسعه‌دهنده» را روشن کنید.
3. روی **Load unpacked** یا «بارگذاری افزونهٔ باز» کلیک کنید.
4. پوشهٔ استخراج‌شده‌ای را انتخاب کنید که فایل `manifest.json` در آن قرار دارد.
5. افزونهٔ **Lumen** را روی نوار ابزار Chrome سنجاق کنید.

## تنظیم مدل

روی آیکن Lumen کلیک کنید، وارد **تنظیمات** شوید و این موارد را وارد کنید:

- **نشانی تکمیل چت** — آدرس کامل API سازگار با OpenAI، برای مثال:
  - `https://api.openai.com/v1/chat/completions`
  - `https://your-provider.example/v1/chat/completions`
  - `http://localhost:11434/v1/chat/completions`
- **کلید API** — برای مدل‌های محلی اختیاری است. اگر کلید را بدون پیشوند `Bearer` وارد کنید، Lumen آن را به‌صورت خودکار اضافه می‌کند.
- **نام مدل** — نام مدل ارائه‌دهندهٔ API.
- **پیام سیستم** — یک پیام پیش‌فرض فارسی از قبل آماده شده است و قابل ویرایش است.

اگر نشانی پایهٔ ارائه‌دهندهٔ شما به `/v1` ختم شود، Lumen به‌صورت خودکار `/chat/completions` را اضافه می‌کند.

## نحوهٔ استفاده

1. یک صفحهٔ معمولی `http://` یا `https://` را باز کنید.
2. روی آیکن Lumen کلیک کنید.
3. گزینهٔ **خلاصه‌سازی این صفحه** را انتخاب کنید.
4. خلاصهٔ Markdown را مشاهده و در صورت نیاز رونوشت کنید.

Lumen متن قابل‌خواندن صفحه را استخراج می‌کند، عناصر معمول رابط کاربری مانند ناوبری و پاورقی را حذف می‌کند، طول متن ارسالی را محدود می‌کند و سپس خلاصه‌ای دقیق و فارسی در قالب Markdown درخواست می‌کند. حتی اگر متن صفحه انگلیسی باشد، خروجی پیش‌فرض فارسی است. خلاصه توسط افزونه ذخیره نمی‌شود.

## حریم خصوصی و دسترسی‌ها

- کلید API در `chrome.storage.local` و داخل پروفایل فعلی Chrome نگهداری می‌شود.
- متن صفحه، عنوان و نشانی آن فقط به Endpoint انتخابی شما ارسال می‌شود.
- هیچ اسکریپت یا کتابخانهٔ خارجی در رابط کاربری بارگذاری نمی‌شود.
- دسترسی‌های `activeTab` و `scripting` فقط پس از کلیک شما روی آیکن، اجازهٔ خواندن صفحهٔ فعال را می‌دهند.
- دسترسی `storage` تنظیمات را به‌صورت محلی ذخیره می‌کند.
- دسترسی به میزبان‌های HTTP و HTTPS برای اتصال به API سازگار با OpenAI، از جمله سرور محلی، لازم است.

فقط از Endpoint مورد اعتماد استفاده کنید. هر کسی که به پروفایل Chrome یا فضای ذخیرهٔ افزونه دسترسی داشته باشد، عملاً به کلید API شما دسترسی دارد.

## فایل‌ها

- `manifest.json` — پیکربندی Chrome Manifest V3
- `background.js` — استخراج متن صفحه و ارسال درخواست API
- `popup.html`، `popup.css`، `popup.js` — رابط کاربری سبک، فارسی و راست‌به‌چپ
- `icons/` — آیکن‌های افزونه
