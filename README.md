# Lumen — خلاصه‌سازی صفحه با هوش مصنوعی

یک افزونهٔ سبک و زیبا برای Chrome که صفحهٔ فعلی را با مدل OpenAI-compatible دلخواه شما خلاصه می‌کند. رابط کاربری فارسی و راست‌به‌چپ است و خلاصهٔ Markdown به‌صورت قالب‌بندی‌شده نمایش داده می‌شود.

## نصب افزونه

برای ساخت بستهٔ قابل انتشار از این دستور استفاده کنید:

```powershell
.\package-extension.ps1
```

سپس فایل `lumen-ai-page-summarizer.zip` را از حالت فشرده خارج کنید. برای بارگذاری محلی:

1. آدرس `chrome://extensions` را باز کنید.
2. گزینهٔ **Developer mode** یا «حالت توسعه‌دهنده» را روشن کنید.
3. روی **Load unpacked** یا «بارگذاری افزونهٔ باز» کلیک کنید.
4. پوشهٔ استخراج‌شده‌ای را انتخاب کنید که فایل `manifest.json` در آن قرار دارد.
5. افزونهٔ **Lumen** را روی نوار ابزار Chrome سنجاق کنید.

> فایل `text` یک فایل محلی حساس است و هرگز نباید در بستهٔ افزونه یا مخزن عمومی قرار گیرد.

## تنظیم مدل

روی آیکن Lumen کلیک کنید، وارد **تنظیمات** شوید و این موارد را وارد کنید:

- **نشانی تکمیل چت** — آدرس کامل API سازگار با OpenAI، برای مثال:
  - `https://api.openai.com/v1/chat/completions`
  - `https://your-provider.example/v1/chat/completions`
  - `http://localhost:11434/v1/chat/completions`
- **کلید API** — برای مدل‌های محلی اختیاری است. اگر کلید را بدون پیشوند `Bearer` وارد کنید، Lumen آن را به‌صورت خودکار اضافه می‌کند.
- **نام مدل** — نام مدل ارائه‌دهندهٔ API.
- **پیام سیستم** — یک پیام پیش‌فرض فارسی از قبل آماده شده است و قابل ویرایش است.

اگر نشانی پایهٔ ارائه‌دهندهٔ شما به `/v1` ختم شود، Lumen به‌صورت خودکار `/chat/completions` را اضافه می‌کند.

برای سرویس‌های آنلاین فقط نشانی‌های `https://` پذیرفته می‌شوند. برای مدل‌های محلی، `http://localhost` و `http://127.0.0.1` مجاز هستند. هنگام اولین خلاصه‌سازی، Chrome فقط برای میزبان API انتخابی اجازهٔ دسترسی می‌گیرد؛ افزونه از ابتدا به همهٔ وب‌سایت‌ها دسترسی دائمی ندارد.

## نحوهٔ استفاده

1. یک صفحهٔ معمولی `http://` یا `https://` را باز کنید.
2. روی آیکن Lumen کلیک کنید.
3. توضیح ارسال داده و گزینهٔ تأیید را بررسی کنید.
4. گزینهٔ **خلاصه‌سازی این صفحه** را انتخاب کنید و در صورت نمایش، اجازهٔ دسترسی به سرویس API را تأیید کنید.
5. خلاصهٔ Markdown را مشاهده و در صورت نیاز رونوشت کنید.

Lumen متن قابل‌خواندن صفحه را استخراج می‌کند، عناصر معمول رابط کاربری مانند ناوبری و پاورقی را حذف می‌کند، طول متن ارسالی را محدود می‌کند و سپس خلاصه‌ای دقیق و فارسی در قالب Markdown درخواست می‌کند. حتی اگر متن صفحه انگلیسی باشد، خروجی پیش‌فرض فارسی است. خلاصه توسط افزونه ذخیره نمی‌شود.

## حریم خصوصی و دسترسی‌ها

- کلید API در `chrome.storage.local` و داخل پروفایل فعلی Chrome نگهداری می‌شود؛ هر کسی که به پروفایل Chrome یا فضای ذخیرهٔ افزونه دسترسی داشته باشد، عملاً به کلید API شما دسترسی دارد.
- پس از تأیید کاربر، متن صفحه، عنوان، نشانی و توضیح صفحه فقط به Endpoint انتخابی ارسال می‌شود.
- افزونه تبلیغ، تحلیل رفتار یا سرور واسط برای جمع‌آوری خلاصه‌ها ندارد.
- دسترسی‌های `activeTab` و `scripting` فقط پس از کلیک شما روی آیکن، اجازهٔ خواندن صفحهٔ فعال را می‌دهند.
- دسترسی `storage` تنظیمات، کلید API و وضعیت رضایت را به‌صورت محلی ذخیره می‌کند.
- دسترسی به میزبان API فقط پس از کلیک روی خلاصه‌سازی و تأیید کاربر درخواست می‌شود؛ دسترسی دائمی به همهٔ سایت‌ها در مانیفست وجود ندارد.
- متن صفحه، کلید API و پیام سیستمی می‌توانند طبق سیاست ارائه‌دهندهٔ API توسط آن سرویس پردازش یا نگهداری شوند. فقط از Endpoint مورد اعتماد استفاده کنید.

متن کامل سیاست در `privacy.html` و `PRIVACY.md` قرار دارد. پیش از انتشار عمومی، اطلاعات تماس را در آن‌ها جایگزین کنید و سیاست را در یک URL عمومی HTTPS منتشر کنید.

## فایل‌ها

- `manifest.json` — پیکربندی Chrome Manifest V3 و دسترسی‌های اختیاری API
- `background.js` — استخراج متن صفحه و ارسال درخواست API
- `popup.html`، `popup.css`، `popup.js` — رابط کاربری سبک، فارسی و راست‌به‌چپ
- `privacy.html` — نسخهٔ داخلی سیاست حفظ حریم خصوصی
- `package-extension.ps1` — ساخت ZIP پاک و بدون فایل‌های محلی حساس
- `icons/` — آیکن‌های افزونه
- `PRIVACY.md` و `STORE_LISTING.md` — متن سیاست و چک‌لیست انتشار
